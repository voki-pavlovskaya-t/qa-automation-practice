# qa-automation-practice

## Источники обучения

Отдельной готовой программы обучения не было — я шла по списку тем из описания 
итоговой задачи на изучение Python, предоставленного для подготовки к экзамену.

Дополнительные ресурсы:
- YouTube — видео по конкретным темам, где требовалось более наглядное объяснение
- Claude (AI) — разбор теории, проверка кода, объяснение ошибок и практические задания
- Материалы из ранее пройденного курса QA Automation в IT-школе Hillel — 
  использовались как база по некоторым темам

**Про AI code review:** по условиям задания предполагалась отправка пул-реквестов 
на AI-ревью. У меня не было возможности выполнить это в полном объёме, так как 
я работала с Claude, а не с Cursor — соответствующий функционал ревью PR доступен 
в Claude только на платной версии. Для примера на нескольких практических работах 
я вручную добавила комментарий от Claude по итогам запроса на ревью моего кода.
